**Category**: SEO | **Severity**: HIGH  
**File**: `src/layouts/Layout.astro`

No `<link rel="canonical">` tag. Every page lacks its canonical URL, risking duplicate content penalties. Astro's `Astro.url` can generate dynamic canonicals.

**Category**: SEO | **Severity**: HIGH | **Status**: ✅ Fixed (2026-06-03)  
**File**: `src/layouts/Layout.astro`

**Category**: Performance | **Severity**: HIGH | **Status**: ✅ Fixed (2026-06-03)

## Priority 3 — Nice to have

### 3.1 No `.nvmrc` — Node version not pinned for devs/CI
**Category**: Tooling | **Severity**: LOW  
**File**: Root (new file)

`package.json` specifies `node >= 22.12.0` but no `.nvmrc` file exists. Cloudflare Pages and developers can't automatically select the correct version.

### 3.2 No `sitemap.xml` or `robots.txt` — Astro has built-in `@astrojs/sitemap`
**Category**: SEO | **Severity**: LOW  
**File**: `astro.config.mjs`

The `@astrojs/sitemap` integration generates `sitemap.xml` automatically. Not installed.

### 3.3 Inconsistent `ø` vs `&oslash;` HTML entities
**Category**: Code quality | **Severity**: LOW  
**File**: `src/pages/index.astro`, `src/pages/historie.astro`

Some areas use `&oslash;` / `&aelig;` while others use literal UTF-8 Norwegian characters in the same file. Normalize to literal characters — Astro handles UTF-8 natively.

### 3.4 Meaningless ternary operator
**Category**: Code quality | **Severity**: LOW  
**File**: `src/pages/slekt.astro:78`

```js
kr {site.membership ? '4000,-' : '4000,-'}
```

`site.membership` is always an object, so both branches return the same value. Replace with a direct value.

### 3.5 Form input classes duplicated 5 times
**Category**: Code quality | **Severity**: LOW  
**File**: `src/pages/bli-medlem.astro`

The same long Tailwind class string is copy-pasted for all 5 form inputs. Extract to a `@layer components` class in `global.css`.

### 3.6 No favicon — not essential but adds polish
**Category**: Branding | **Severity**: LOW  
**File**: `src/layouts/Layout.astro`

No `<link rel="icon">` or `<link rel="apple-touch-icon">` tag. The logo at `/images/logo.png` could serve as a favicon with minor processing.

### 3.7 No `<link rel="preload">` for logo or hero images
**Category**: Performance | **Severity**: LOW  
**Files**: `src/layouts/Layout.astro`, `Hero.astro`

Above-the-fold critical resources (logo and hero images) could benefit from `<link rel="preload">` to reduce LCP.

### 3.8 `vite` override in `package.json` — unnecessary
**Category**: Tooling | **Severity**: LOW  
**File**: `package.json`

```json
"overrides": { "vite": "^7" }
```

Astro 6 manages its own Vite version internally. The override may cause superfluous peer dependency warnings.
